   VH_Dimension         YBP_D_VH_DIM
   VH_DimStatus         YBP_D_VH_DIMSTATUS

 TEXT
   ValueTexts           YBP_D_TEXTS   – Domain + Code + Language composite key

 STATUS CASCADE  (auto-computed via service event handlers)
   Dim_Status = E0005 Authorized   ⟹  PT_Status  = E0005 Operational
   PT_Status  = E0005 Operational  ⟹  Partner_status = E0002 Active
   Reverse: revert when none qualify

   Check (Partner_Type, Dim_id) exists in C_PartnerTypeDimMap.
   Reject with error if not found.
